# Icons

Many interactive items use an icon to represent the action that will follow suit. Almost all icons should be 32x32px with a stroke width of 1.5 and a fill and/stroke color of `currentColor`. My recommended icon set is [Tabler Icons](https://tabler.io/icons). They have a lot of option and styles, and are best fit for this style of mobile based content.
