# Card

To contain and group content in a section, cards are used. Usually to hold interactive components, text, or even images.

`p` Elements will automatically be given padding treatment. Also, when expanding the navbar from medium to large size, the card will automatically shift right to accommodate the navbar moving to the left.

```vue-html
<body>  
    <section>
        <div.card>
            <p>...</p>
            <p>...</p>
        </div>
    </section>
</body>
```

If you dont have multiple sections, feel free to just have a card in the main `body` section.

```vue-html
<body>
    <div.card>
        <p>...</p>
        <p>...</p>
    </div>
</body>
```
