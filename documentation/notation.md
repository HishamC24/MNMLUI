# Notation

To simplify code blocks, clean up clutter, and remove repetition, HTML code here will be represented somewhat differently. Elements/tags will be represented as normal:

```vue-html
<div></div>
```

But, to clean up classes and ID's, they will be represented with `.` and `#` respectively, in replacement of `class=""` and `id=""`. Here is an example of simplified code, and what its actual representation is.

```vue-html
<div.glassy.button.tinted#goToHome>
    <svg>...</svg>
</div>
```

```html
<div class="glassy button tinted" id="goToHome">
    <svg>...</svg>
</div>
```

You can always go to the [/HTML/](../HTML) in the Github Repository to find examples of all these items and components.
